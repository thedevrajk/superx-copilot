# SuperX Copilot

Reply drafts for X. It reads the post, picks a reply format, and inserts text. You press Reply.

Posts and replies are different. This extension only drafts replies.

## Load

1. Unzip this folder.
2. Open `chrome://extensions`.
3. Turn on Developer mode.
4. Choose Load unpacked and select this folder.
5. Optional: open the extension settings and configure any API (Gemini, DeepSeek, OpenRouter, Groq, or custom). With no key, drafts stay on device.

## Use

On x.com or twitter.com, Draft appears in each post's action bar.

- The read is the extension's take on the post, before any line.
- Three reply formats are chosen for that kind of post.
- Drop a line to keep it out of the next run.
- Insert puts the text in an open reply box, or copies it if the box is closed.
- It never presses Reply.
